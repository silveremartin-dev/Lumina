## 7. Règle Générative : Comment forger un mot nouveau ?

Pour créer un mot conforme :
1. Choisir la **catégorie sémantique principale** (C1) :
   `T` (Temps), `K` (Objet/Espace), `P` (Nombre/Calcul), `S` (Sensation), `M` (Humain), `F` (Parole), `L` (Mouvement), `SH` (Idée), `J` (Technique).
2. Définir la **classe grammaticale** (V1) :
   `-A-` pour un Nom, `-I-` pour un Verbe, `-U-` pour un Adjectif, `-O-` pour un Lieu/Groupe.
3. Choisir le **radical spécifique** (C2V2).
4. Exemple :
   - Robot = `J` (Outil) + `-A-` (Nom) + `B-A` (Corps/Agent) = `JABA` (automate mécanique).
   - Programmer = `J` (Technique) + `-I-` (Verbe) + `P-O` (Calcul) = `JIPO` (coder / instruire une machine).
